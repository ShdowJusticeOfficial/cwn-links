# Community Watch Network (CWN) Links

The official Community Watch Network (CWN) links page, providing quick access to CWN services, projects, investigations, social platforms, documentation, and public resources.

Designed to be lightweight, responsive, and accessible across desktop, mobile, and VR browsers.

---

## 🌐 Features

- Modern responsive interface
- Mobile, desktop, and VR browser support
- Fast-loading static website
- Central hub for all official CWN links
- Featured investigations and public resources
- Staff directory
- Executive team information
- Department information
- Community mission statement
- Public transparency information
- Malware Scanner
- Easy deployment with GitHub and Vercel

---

## 🛠️ Technology Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Git
- GitHub
- Vercel

## 🚀 Local Development

### Clone the repository

```bash
git clone https://github.com/ShdowJusticeOfficial/cwn-links.git
```

### Enter the project directory

```bash
cd cwn-links
```

### Run locally

Simply open `index.html` in your preferred web browser.

No build tools or package installation are required.

---

## 🌍 Deployment

This project is automatically deployed using **Vercel** whenever changes are pushed to the main branch.

## 🎯 Purpose

The CWN Links page serves as the central public hub for Community Watch Network, allowing visitors to quickly access:

- Official websites
- Community resources

- Investigations
- Public reports
- Safety tools
- Featured projects
- Social media
- Contact information

## 🔒 Security

This website is designed as a static frontend and does not require visitors to create accounts or submit sensitive information.

Security best practices include:

- HTTPS deployment
- Static asset hosting
- No unnecessary third-party trackers
- Responsive and accessible design
