# Community Watch Network (CWN) Links

The official **Community Watch Network (CWN)** links page, providing quick access to CWN services, projects, investigations, staff information, social platforms, public resources, and community tools.

Built to be lightweight, responsive, and accessible across desktop, mobile, and VR browsers.

---

## ✨ Features

* Modern responsive design
* Mobile, desktop, and VR browser support
* Fast-loading static website
* Central hub for official CWN resources
* Executive team information
* Staff directory
* Department directory
* Community mission statement
* Public transparency information
* Featured investigations and exposes
* Malware Scanner
* Official contact links
* GitHub & Vercel deployment

---

## 🛠 Technology Stack

* HTML5
* CSS3
* JavaScript (Vanilla)
* Git
* GitHub
* Vercel

## 🚀 Local Development

Clone the repository:

```bash
git clone https://github.com/ShdowJusticeOfficial/cwn-links.git
```

Open the project folder:

```bash
cd cwn-links
```

Launch the website by opening `index.html` in your preferred web browser.

No additional software or build tools are required.

---

## 🌐 Deployment

This project is automatically deployed through **Vercel** whenever changes are pushed to the repository.
