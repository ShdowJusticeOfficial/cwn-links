# CWN VRC Profile

Official profile page for the Community Watch Network (CWN) VRChat presence.

## Features

- Modern responsive design
- Mobile friendly
- Fast loading
- Static HTML website
- GitHub + Vercel deployment

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Local Development

Clone the repository:

```bash
git clone https://github.com/ShdowJusticeOfficial/cwn-links.git
```

Open the project:

```bash
cd cwn-links
```

Open `index.html` in your browser.

## Deployment

This website is automatically deployed using Vercel.
